# Контроль кружков инвентаризации

Бот читает видеокружки и подпись к ним или ответ автора на кружок вида `Ашрафи 27.09`. Сверяет филиал, дату и назначенного бухгалтера с `schedule.json`, пишет результат в SQLite и отвечает в группе. `/today` показывает план на сегодня. Часовой пояс Asia/Tashkent. Также принимает обычное видео с подписью.

Бухгалтер пишет в группе `/iam ФАМИЛИЯ ИМЯ ОТЧЕСТВО` (ФИО из графика). Администратор группы отвечает `/approve` **на исходное сообщение `/iam`**. Вручную указывать Telegram ID не требуется. До подтверждения результат «бухгалтер не установлен», поэтому чужой человек не получит статус «совпадает» простым вводом чужого ФИО.

Статусы: `совпадает`, `сдвиг по дате` (в пределах ±2 дней), `вне графика`, `чужой филиал`, `бухгалтер не установлен`. Если филиал назначен одному бухгалтеру, а видео отправил другой подтверждённый бухгалтер, это фиксируется как `чужой филиал`, даже при правильной дате.

`/week` показывает предыдущую календарную неделю (понедельник–воскресенье), `/month` — предыдущий календарный месяц. Сводка включает все отклонения и филиалы без подтверждённого совпадения. Автоматическая отправка в группу: каждый понедельник в 09:00 — прошлая неделя; первого числа в 09:00 — прошлый месяц. Для автоматической отправки обязателен `GROUP_ID`. Если сервис не работал в момент отправки, он повторит попытку в течение часа после восстановления (09:00–09:59).

## Запуск

1. Создайте отдельного бота в BotFather, добавьте его в группу; отключите Privacy Mode, чтобы он видел сообщения и ответы. Не используйте токен другого работающего бота.
2. Укажите `BOT_TOKEN` как секрет среды и `GROUP_ID` (числовой ID группы, рекомендуется). Не кладите токен в GitHub.
3. Запустите отдельный **постоянно работающий worker** из корня проекта: `pip install -r round_video_bot/requirements.txt`, затем `python round_video_bot/main.py`.
4. Для Render задайте Root Directory пустым, Start Command `python round_video_bot/main.py`, тип Background Worker. Подключите постоянный диск и задайте `DATABASE_PATH=/var/data/events.sqlite3`; иначе история пропадёт при пересоздании контейнера.

Регистрация ФИО и отчёты сохраняются в SQLite на постоянном диске. Исторические проверки остаются с тем статусом, который был на момент отправки; если администратор подтвердил бухгалтера позднее, старые записи нужно проверить повторно. Для очередного месяца замените `schedule.json` данными нового графика. Бот не может определить физическую личность на видео — подтверждается учётная запись Telegram администратором группы. GitHub сам по себе бота не запускает круглосуточно.
